autodiff_dual_numbers autodiff_dual_numbers.f90

Forward-mode dual numbers and overloaded arithmetic and intrinsic operations. Supplies the real64 kind used for values and directional derivatives. Dual-number value type; each instance stores a value and one directional derivative. Assignment conversions between dual numbers and real or integer scalars. Arithmetic operators propagate derivatives using the corresponding calculus rules. Equality and ordering comparisons use values only and ignore derivative seeds. Remaining value-only ordering comparisons. Overloaded real-valued intrinsic functions with derivative propagation. Additional inverse trigonometric, hyperbolic, and error functions. Selection and sign intrinsics propagate the derivative of the selected or magnitude operand.

autodiff_hyperdual_numbers autodiff_hyperdual_numbers.f90

Second-order forward-mode hyper-dual numbers and overloaded operations. Hyper-dual number type carrying a value, two first derivatives, and a mixed second derivative. Assignment conversions between hyper-dual numbers and real or integer scalars. Arithmetic operators propagating first and mixed second derivatives. Comparisons use values only and ignore derivative seeds. Remaining value-only ordering comparisons. Overloaded real-valued intrinsic functions with second-order derivative propagation.
