public subroutine jacobian(fcn, x, J, work, args, nthreads)

Compute a vector function's Jacobian by seeding each input basis direction.

When 'nthreads' is greater than one and the library is built with OpenMP, the Jacobian columns are evaluated in parallel. In this case, the user procedure must be thread-safe and must not modify shared state through 'args' without synchronization.
