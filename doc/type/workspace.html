procedure, public :: resize => wrk_resize

Allocates or grows the workspace buffers.

  • private subroutine wrk_resize(work, n, m, nthreads)

    Allocates or grows the workspace buffers to at least the requested dimensions. Buffers are never shrunk. When growth is required, a buffer is sized to the larger of the request and twice its previous size. Buffer contents are not preserved on growth.

    Arguments

    Type IntentOptional Attributes Name
    class(workspace), intent(inout) :: work

    Workspace whose input and output buffers are managed.
    integer, intent(in) :: n

    Required number of input elements.
    integer, intent(in) :: m

    Required number of output elements.
    integer, intent(in), optional :: nthreads

    Required number of per-thread buffer columns. If omitted, one column is required.
