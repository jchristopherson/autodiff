type, public :: hyperdual_workspace

Allocatable temporary arrays used during second-order automatic differentiation.


Components

Type Visibility Attributes Name Initial
type(hyperdual), public, allocatable, dimension(:,:) :: xd_pool

Per-thread hyper-dual-valued input buffers, one column per thread. Serial evaluations use the first column.

procedure, public :: resize => hwrk_resize

Allocates or grows the workspace buffers.

  • private subroutine hwrk_resize(work, n, nthreads)

    Allocates or grows the workspace buffers to at least the requested dimensions. Buffers are never shrunk. When growth is required, a dimension is sized to the larger of the request and twice its previous size. Buffer contents are not preserved on growth.

    Arguments

    Type IntentOptional Attributes Name
    class(hyperdual_workspace), intent(inout) :: work

    Workspace whose input buffers are managed.
    integer, intent(in) :: n

    Required number of input elements per thread.
    integer, intent(in), optional :: nthreads

    Required number of per-thread buffer columns. If omitted, one column is required.
